# Resource: postgresql_event_trigger

Manages a PostgreSQL Event Trigger. Event triggers are used to execute functions in response to certain database events, such as DDL commands.

## Example Usage

```terraform
# Example: PostgreSQL Event Trigger
#
# This example creates an event trigger that fires on DDL commands.
# Event triggers are database-wide triggers that capture DDL events.

# Prerequisites: The exec_func must already exist
# This example assumes a function named 'alter_object_owner' exists

# Basic event trigger for CREATE TABLE statements
resource "postgresql_event_trigger" "track_table_creation" {
  name      = "track_table_creation"
  database  = "postgres"
  event     = "ddl_command_end"
  tags      = ["CREATE TABLE"]
  exec_func = "alter_object_owner"
  enabled   = true
  comment   = "Tracks when new tables are created"
  owner     = "postgres"
}

# Event trigger for multiple DDL commands
resource "postgresql_event_trigger" "track_schema_changes" {
  name      = "track_schema_changes"
  database  = "postgres"
  event     = "ddl_command_end"
  tags      = ["CREATE TABLE", "ALTER TABLE", "DROP TABLE"]
  exec_func = "log_schema_changes"
  enabled   = true
  comment   = "Logs all table-related schema changes"
  owner     = "postgres"
}

# Event trigger for table rewrites (disabled by default)
resource "postgresql_event_trigger" "prevent_table_rewrite" {
  name      = "prevent_table_rewrite"
  database  = "postgres"
  event     = "table_rewrite"
  tags      = [] # table_rewrite event doesn't use tags
  exec_func = "check_rewrite_safety"
  enabled   = false
  comment   = "Prevents unsafe table rewrites when enabled"
  owner     = "postgres"
}

# Output the event trigger names for reference
output "event_trigger_names" {
  value = [
    postgresql_event_trigger.track_table_creation.name,
    postgresql_event_trigger.track_schema_changes.name,
    postgresql_event_trigger.prevent_table_rewrite.name,
  ]
  description = "Names of created event triggers"
}
```

## Schema

### Required

- `event` (String) The type of event that the trigger responds to. Valid values are `ddl_command_start`, `ddl_command_end`, `sql_drop`, etc.
- `exec_func` (String) Name of the function to be executed when the event trigger is fired.
- `name` (String) The name of the event trigger. Must be unique within the database.

### Optional

- `comment` (String) Comment associated with the Postgresql Event Trigger.
- `database` (String) Name of the database where the Event Trigger is located. If not specified, the provider's configured database will be used.
- `enabled` (Boolean) Whether the event trigger is enabled. Defaults to `true`.
- `owner` (String) The owner of the event trigger. If not specified, the owner will be the User used in the provider's configuration.
- `tags` (Set of String) A set of tags associated with the event trigger. Tags can be used for categorization and filtering.

### Read-Only

- `id` (String) The unique identifier for the event trigger, in the format `<database_name>.<event_trigger_name>`
- `last_updated` (String) Timestamp of the resource's last modification
