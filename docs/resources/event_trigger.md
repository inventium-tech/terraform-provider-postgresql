# Resource: postgresql_event_trigger

Manages a PostgreSQL Event Trigger. Event triggers are used to execute functions in response to certain database events, such as DDL commands.

## Example Usage

```terraform
resource "postgresql_event_trigger" "test" {
  name      = "test_trigger_one"
  database  = "postgres"
  event     = "ddl_command_end"
  tags      = ["CREATE TABLE"]
  exec_func = "alter_object_owner"
  enabled   = true
  comment   = "Test event trigger"
  owner     = "postgres"
}
```

## Schema

### Required

- `event` (String) The type of event that the trigger responds to. Valid values are `ddl_command_start`, `ddl_command_end`, `sql_drop`, etc.
- `exec_func` (String) Name of the function to be executed when the event trigger is fired.
- `name` (String) The name of the event trigger. Must be unique within the database.

### Optional

- `comment` (String) Comment associated with the Postgresql Event Trigger.
- `database` (String) Name of the database where the Event Trigger is located. If not specified, the provider's configured database will be used.
- `enabled` (Boolean) Whether the event trigger is enabled. Defaults to `true`.
- `owner` (String) The owner of the event trigger. If not specified, the owner will be the User used in the provider's configuration.
- `tags` (Set of String) A set of tags associated with the event trigger. Tags can be used for categorization and filtering.

### Read-Only

- `id` (String) The unique identifier for the event trigger, in the format `<database_name>.<event_trigger_name>`
- `last_updated` (String) Timestamp of the resource's last modification
