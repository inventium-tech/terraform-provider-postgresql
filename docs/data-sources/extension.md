# Data Source: postgresql_extension

Retrieves information about a PostgreSQL extension. [PostgreSQL documentation](https://www.postgresql.org/docs/current/sql-createextension.html)

## Example Usage

```terraform
data "postgresql_extension" "uuid_ossp" {
  name = "uuid-ossp"
}

output "extension_version" {
  value = data.postgresql_extension.uuid_ossp.version
}
```
